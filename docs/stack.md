# Технологічний стек SkyGuard

| Шар | Технологія | Чому саме вона |
|---|---|---|
| API | **Python 3.12 + FastAPI** | Автоматична OpenAPI-документація, валідація через Pydantic, нативна підтримка WebSocket для тривожного режиму (SG-21) |
| ORM / міграції | **SQLAlchemy 2.0 + Alembic** | Типізовані моделі; зміни схеми лише через версіоновані міграції |
| БД | **PostgreSQL 16** | Транзакції, CHECK-обмеження для правил якості даних, тригери для незмінного журналу аудиту, JSONB, вбудований `sha256()` |
| Драйвер | psycopg 3 | Сучасний драйвер PostgreSQL з бінарними колесами |
| Конфігурація | pydantic-settings + `.env` | Секрети не потрапляють у репозиторій |
| ASGI-сервер | Uvicorn | Стандарт для FastAPI |
| Фронтенд | Leaflet + OpenStreetMap (SG-9) | Відкриті картографічні дані, без ключів API |
| Контейнеризація | Docker + docker compose | Запуск з нуля однією командою (SG-24) |
| Якість коду | pytest, ruff, GitHub Actions | Тести схеми проти справжнього PostgreSQL у CI |

## Ключові рішення

**Координати — `NUMERIC(9,6)`, без PostGIS.** Точність 6 знаків ≈ 0,1 м. Для прототипу відстань рахується формулою Haversine у застосунку (SG-21), PostGIS не потрібен. Якщо знадобиться пошук «найближчих N укриттів» на великих обсягах — додається розширення PostGIS окремою міграцією без зміни API.

**Довідники — `VARCHAR + CHECK`, а не нативні `ENUM`.** Нове значення додається звичайною міграцією без `ALTER TYPE`.

**Правила якості даних дублюються в БД.** DQ-1 і DQ-2 перевіряє API (з кодом помилки `422`), але CHECK-обмеження на `status_report` гарантують, що звіт зі статусом `ACCEPTED`, який порушує правило, не потрапить у БД навіть через помилку в коді.

**Незмінність аудиту забезпечує БД, а не застосунок.** Тригери забороняють `UPDATE / DELETE / TRUNCATE` для `audit_log`, а хеш-ланцюжок дозволяє виявити втручання навіть з боку адміністратора БД (функція `audit_log_verify()`).

**Синхронний SQLAlchemy.** Простіше для команди; FastAPI виконує синхронні ендпоїнти у пулі потоків. WebSocket-розсилка (SG-21) асинхронна й від цього не залежить.
