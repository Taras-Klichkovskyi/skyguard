## 📌 Про проєкт

**SkyGuard** — це інженерний прототип муніципальної інформаційної системи керованого обміну геопросторовими даними про фонд захисних споруд цивільного захисту.

Ключова архітектурна концепція проєкту — **Data Governance by Design** (управління даними, закладене на етапі проєктування). Система організовує безпечний інформаційний простір (*Governed Data Space*) для взаємодії між постачальниками даних (коменданти, чергові ДСНС, активні мешканці) та споживачами (громадяни під час тривоги, муніципальні аналітики, координатори екстрених служб).

## 🚀 Швидкий запуск (Docker Compose)

Найпростіший спосіб підняти повну екосистему проєкту (БД PostgreSQL 16 + FastAPI бекенд + Nginx веб-клієнт):

```bash
# 1. Створіть конфігураційний файл середовища
cp .env.example .env

# 2. Запустіть усі сервіси через Docker Compose
docker compose up -d --build

# 3. Наповніть базу демонстраційними укриттями Львова та тестовими ролями
docker compose exec api python -m app.seed
```

## 🔒 Політика Data Governance та захист даних

Система SkyGuard реалізує захист даних відповідно до **Закону України «Про захист персональних даних» № 2297-VI**, **Регламенту ЄС 2016/679 (GDPR, ст. 25 Privacy by Design)** та міжнародного стандарту **ISO/IEC 27001**:

### 1. Чотирирівнева класифікація даних
* **L1: Публічні (PUBLIC)** — реєстр укриттів (адреси, координати входів WGS-84, пандуси, відкритий/закритий статус). Доступ без авторизації.
* **L2: Внутрішні (INTERNAL)** — телеметрія електронних замків Smart Lock (рівень заряду, сигнал зв'язку контролерів ESP32). Доступ закріпленому коменданту та ДСНС.
* **L3: Конфіденційні (CONFIDENTIAL)** — службові номери телефонів та ПІБ комендантів, зведення завантаженості, журнал інцидентів. Доступ суворо за RBAC-ролями.
* **L4: Персональні (SENSITIVE)** — точні GPS-координати мешканців під час навігації та викликів SOS. Обробляються виключно за згодою (Opt-in) і не зберігаються назавжди (термін сесії $\le 30\text{ хв}$).

### 2. Керування згодою суб'єкта (Consent Management)
* Передача координат користувача вимагає **явного дозволу (Opt-in)**.
* **Right to Withdraw:** Мешканець може в будь-яку мить відкликати згоду одним кліком на пульсуючу цятку геолокації в шапці (статус `REVOKED`), після чого збір геоданих негайно блокується з кодом `403 CONSENT_REQUIRED`.

### 3. Детерміновані правила контролю якості даних (Data Quality Rules)
* **DQ-1: Geofence ($\le 100\text{ м}$)** — подача звіту про стан дверей укриття дозволена лише в радіусі 100 метрів від входу. Відстань розраховується за формулою гаверсинуса (Haversine Formula). При $d > 100\text{ м}$ сервер повертає `422 GEOLOCATION_OUT_OF_BOUNDS`, а сирі координати знищуються.
* **DQ-2: Freshness ($\le 30\text{ хв}$)** — актуальність інформації про відкритість укриття. Дані старші 30 хвилин маркуються як застарілі (`STALE`).
* **DQ-3: Quorum (Кворум)** — зміна публічного статусу укриття на основі звітів мешканців вимагає набору ваги голосів $\ge 3$ протягом 15 хвилин, захищаючи карту від паніки та дезінформації.

### 4. Незмінний журнал аудиту (Immutable Audit Trail)
* Усі події (надання/відкликання згоди, відхилення доступу 403, помилки якості 422, зміна статусів) фіксуються в журналі, зв'язаному криптографічним хеш-ланцюгом **SHA-256** (blockchain-style). Кожен новий блок містить хеш попереднього запису (`previous_hash`), унеможливлюючи непомітну модифікацію історії дій адміністраторами.

## 📱 Мобільний та веб-інтерфейс (Leaflet Touch UI)

Фронтенд спроєктовано за принципом **Mobile-First**:
* **Адаптивна сенсорна шапка:** оптимізована для екранів від 320px до десктопів; містить компактні круглі кнопки:
  - 🟢 / 🔴 **Пульсуюча цятка GPS** (статус передачі геопозиції та згоди).
  - 👤 **Аватар профілю** (швидкий вхід та зміна ролі RBAC).
  - 🚨 **Сирена** (симуляція сповіщення про повітряну тривогу).
* **Нижня шторка інформації про укриття (Bottom Sheet):**
  - **Peek Mode (140px):** компактна картка залишає $>80\%$ екрана відкритим для огляду карти.
  - **Expanded Mode (78vh):** плавне розгортання свайпом вгору або кнопкою для перегляду зручностей (генератор, Starlink, вода, пандуси) та телеметрії.
* **SafeRoute коридори:** побудова реальних пішохідних маршрутів тротуарами міста за допомогою інтеграції з сервером **OSRM**.
* **Жива інтеграція з alerts.in.ua:** моніторинг реального статусу повітряної тривоги у Львівській області в реальному часі.

## 💻 Локальна розробка без Docker

```bash
# 1. Створення та активація віртуального оточення Python
python3 -m venv .venv
source .venv/bin/activate

# 2. Встановлення залежностей розробника
pip install -r requirements-dev.txt

# 3. Підняття лише бази даних PostgreSQL у Docker
docker compose up -d db

# 4. Застосування міграцій бази даних Alembic
alembic upgrade head

# 5. Запуск бекенду FastAPI з автоматичним перезавантаженням
uvicorn app.main:app --reload --port 8000

# 6. В окремому терміналі запуск локального веб-сервера фронтенду:
python3 -m http.server 8085 --directory frontend
```

### Запуск автоматизованих тестів:

```bash
# Запуск повного набору тестів із перевіркою покриття (поріг > 70%)
pytest -v --cov=app

# Статичний аналіз та форматування коду Ruff
ruff check . && ruff format --check .
```
